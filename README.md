### 2. 전처리

**사고 데이터**
```python
# 사고일시 정규화 → 기상 데이터 조인 키 생성
df['사고일시'] = pd.to_datetime(df['사고일시'], errors='coerce')
df['사고일_dt'] = df['사고일시'].dt.normalize()
```

- 공사비 구간 → 17단계 순서형 인코딩 (50억 미만: 소규모현장=1)
- 공정율 구간 → 중앙값 수치화 (10% 미만→5, 90% 이상→95)
- 고위험 공종 플래그: 가설공사, 해체·철거, 철골, 거푸집, 비계, 굴착·발파
- 공종_빈도가중치: 공종별 사고 발생 빈도 비율 산출

**기상 데이터**
- 수치형 변환 (pd.to_numeric) 및 DOY 기준 평년 평균 산출
- 전국 평균값 사용 이유: 사고 데이터가 서울·경기권 집중 → 지역 분리 시 타 지역 표본 부족

---

### 3. 기상 파생변수 (11개)

> 핵심 설계 원칙: **단발성 당일 기상이 아닌 7일 누적 기후 스트레스** 정량화

| 변수명 | 산출 방식 | 설계 근거 |
|---|---|---|
| ATD_7d | 최근 7일간 (평균기온 - 평년기온) 합계 | 구조물 열팽창 누적 주기, 근로자 열피로 패턴 |
| TSI_3d | 최근 3일 일교차 × 시간가중치(0.5/0.33/0.17) | 단기 온도 급변 충격 정량화 |
| 누적강수_7d | 최근 7일 일강수량 합계 | 지반 연약화 누적 지표 |
| 누적풍속_7d | 최근 7일 평균풍속 이동평균 | 고소작업 위험성 누적 지표 |
| 기온변동성_7d | 최근 7일 평균기온 표준편차 | 온도 급변 불안정성 정량화 |
| 폭염_연속_7d | 7일 내 최고기온 ≥ 33°C 일수 | 극한 기상 지속성 |
| 한파_연속_7d | 7일 내 최저기온 ≤ -12°C 일수 | 콘크리트 양생 기간(7~8일) 영향 |
| 강수_연속_7d | 7일 내 일강수량 ≥ 10mm 일수 | 지반 연약화 지속성 |
| 강풍_연속_7d | 7일 내 평균풍속 ≥ 9m/s 일수 | ⚠️ 전국 평균값 임계값 미달로 전체 0 → 모델 학습 제외 |
| 날씨_위험도_복합 | 위 지표들 가중 합산 | 복합 기상 위험 종합 지표 |
| magnitude_score | 날씨_위험도_복합 Min-Max 정규화(0~1) | Layer 2 Magnitude 지표 |

```python
df['온도편차'] = df['평균기온'] - df['평년기온']
df['ATD_7d'] = df['온도편차'].rolling(7, min_periods=1).sum()
```

### 4. 데이터 통합 (LEFT JOIN)

| 항목 | 내용 |
|---|---|
| 조인 방식 | LEFT JOIN (사고 레코드 기준) |
| 조인 키 | 사고일_dt = 날씨 일시 (날짜 단위 1:1 매칭) |
| 매칭률 | **100%** (사고 2019.07~2025.12 ⊆ 기상 2019.01~2025.12) |

### 5. 교차 파생변수 (7개)

> 날씨 피처 × 현장 피처의 **상호작용(Interaction)** — RIA 핵심 예측 신호

| 변수명 | 설계 근거 |
|---|---|
| risk_heat_process | ATD_7d 절댓값 × 고위험공종여부 — 폭염/한파 누적 + 고위험 공종 동시 발생 |
| risk_rain_progress | 누적강수_7d × (1 - 공정율/100) — 공정 초기일수록 강우 위험 증가 |
| risk_cold_concrete | 한파_연속_7d × 콘크리트공사 여부 — 한파 중 양생 불량·동결 위험 |
| weather_scale_interact | magnitude_score × (1/공사비_순위) — 소규모 현장 기상 스트레스 취약성 |
| heat_foreign_exposure | 폭염_연속_7d × 외국인비율 — 외국인 근로자 폭염 노출 취약성 |
| heat_elderly_exposure | 폭염_연속_7d × 고령자비율 — 고령 근로자 폭염 노출 취약성 |
| ~~risk_wind_scaffold~~ | ~~누적풍속_7d × 고위험공종여부~~ → 바람 누적 의미 없어 제거 |

## 주요 EDA 인사이트

### 소규모 현장 집중 위험
- 소규모(50억 미만) 중대재해율 **10.1%** vs 대형 현장 **2.9%** → 약 3.5배
- 전체 중대재해 1,675건 중 778건(46.4%)이 소규모 현장 발생

### 날씨 × 공종 복합 신호

| 조건 | 공종 | 중대재해율 | Lift |
|---|---|---|---|
| 강수_연속 ≥ 3일 | 철골공사 | 10.98% | 2.67x |
| 폭염_연속 ≥ 2일 | 토공사 | 9.28% | 2.26x |
| 최저기온 ≤ -5°C | 철골공사 | 7.69% | 1.87x |
| 누적강수_7d ≥ 100mm | 기계설비공사 | 7.55% | 1.83x |

> **날씨가 위험을 직접 만드는 것이 아니라 특정 공종의 취약점을 증폭시킴**

### 시간대·요일 신호
- 중대재해율 높은 시간: 12시(8.09%), 7시(5.53%)
- 중대재해율 높은 요일: 일요일(6.71%)

## 데이터 구조적 한계

**전국 단위 평균 기상값 사용**으로 세 가지 문제가 동시에 파생됨.

- 지역별 실제 기상 조건 미반영 → 국지성 기상 이벤트 과소평가 가능
- 강풍_연속_7d 전체 0 고정 → 전국 평균 풍속이 임계값(9m/s) 미달
- 수도권 외 지역 표본 부족 → 지역 분리 분석 불가

**시도별 관측소 데이터 연계** 시 세 문제 동시 해소 가능.

추가 한계:
- 사고 발생 행만 존재 → '사고 발생 시 중대재해일 확률'만 학습 가능. '오늘 사고 날 확률'은 무사고일 데이터 필요
- Label Leakage: C_RPI·위험등급은 날씨 파생변수로부터 룰 기반 산출 → 모델 학습 시 제외 필요
